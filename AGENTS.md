# Project plotting preferences

Apply these user preferences to new and revised figures in this repository:

- Do not draw national or administrative borders on maps. Retain coastlines. If using a country polygon basemap, dissolve the polygons before drawing their outlines.
- Use English for legends, titles, axes, annotations and figure captions. Chinese comments and usage instructions are fine.
- Use a restrained Nature/Science-inspired style: white backgrounds, consistent Arial/Helvetica or a similar sans-serif font, thin axes and lines, legible labels at the final figure size, and accessible colours. Avoid decorative shading, background gridlines and oversized titles.
- Use sequential colour scales for nonnegative activity; explicitly label logarithmic scales and units. Keep missing/unsampled areas distinct from measured zero values.
- Generate scientific figures from actual data with R/Python plotting tools. Retain source identifiers, versions, aggregation methods and validation alongside the outputs.
- Export preview PNGs and editable vector artwork when practical. Treat the style as a research default; check the target journal's current specifications for a submission.
- Keep private datasets, derived tables and rendered figures in ignored output/data directories. Publish reusable code and documentation only.

Reference: [Nature research figure guide](https://research-figure-guide.nature.com/figures/preparing-figures-our-specifications/).
